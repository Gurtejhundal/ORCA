# Website Page Language

The full website should inherit the hero design.

## Home

Hero:
- immersive ocean;
- boat;
- query bar;
- minimal controls.

Below hero:
- scroll transitions from live ocean to controlled dark sections.

Suggested order:
1. How ORCA Works
2. What ORCA Understands
3. Fisherman Use Case
4. Safety + Route Intelligence
5. Data Sources
6. Regional Language Support
7. Final Ask ORCA CTA

## How ORCA Works

Avoid generic process cards.

Use:
- one continuous ocean/geospatial canvas;
- small labels;
- thin connectors.

Flow:

```text
Ask
→ Understand
→ Check Data
→ Analyse Sea
→ Compare Risk
→ Guide Fisherman
```

## Capabilities

Use large editorial rows, not six equal cards.

Examples:
- Fishing Zones
- Sea Conditions
- Marine Alerts
- Safe Routes
- Boundary Awareness

Each capability:
- text on one side;
- marine visualization on the other.

## Data Sources

Dark quiet section.

Use minimal provider marks and source descriptions.

Do not build a logo wall with giant tiles.

## Use Cases

Primary:
- fisherman.

Secondary:
- researchers;
- authorities;
- maritime operators.

Keep fisherman visually dominant.

## About

More editorial.

Use:
- large ocean imagery;
- minimal glass;
- readable text.

## Final CTA

Return to ocean language.

Example:

```text
Know the sea before you sail.

[ Ask ORCA about the sea... ]
```

The website should visually loop back to the hero.
