# ORCA Design Language System

This pack defines the visual and interaction language for the entire ORCA website.

## North Star

The generated `REFERENCE_HERO.png` is the **primary visual reference**.

The website should feel like:

> A calm, intelligent, premium marine operating layer floating over a living ocean.

Not:

> A generic AI dashboard, gaming HUD, or glassmorphism-heavy hackathon website.

## Core principles

1. **Ocean first**
2. **Minimal interface**
3. **Liquid glass, not blue glow**
4. **Contextual intelligence, not permanent widgets**
5. **Top-down marine perspective**
6. **Calm motion**
7. **Geospatial information embedded into the scene**
8. **Every overlay must have a purpose**
9. **The hero image is the design benchmark**
10. **The rest of the site must inherit the same restraint**
