# Definition of Done

The Gateway MVP is DONE only when every P0 item below passes.

## Core

- [ ] User can submit flagship natural-language query.
- [ ] Query becomes structured intent.
- [ ] Planner creates visible executable tasks.
- [ ] At least three data/evidence categories are used.
- [ ] Every measurement shows source and time.
- [ ] Data is labelled LIVE/CACHED/STATIC/DEMO.
- [ ] Candidate fishing zones render on map.
- [ ] Hazards/geofences render on map.
- [ ] Safety score is deterministic.
- [ ] Opportunity score is deterministic.
- [ ] At least two routes/options can be compared.
- [ ] Restricted-zone intersection is deterministic.
- [ ] Recommendation changes when fixture/live conditions change.
- [ ] "Why not nearest?" produces a real comparison.
- [ ] Explanation introduces no unsupported numbers.
- [ ] External API failure does not crash the app.
- [ ] Offline/cached demo path exists.

## Presentation

- [ ] Judge sees recommendation within 5 seconds.
- [ ] One team member can explain architecture in 30 seconds.
- [ ] One team member can explain scoring without vague AI language.
- [ ] One team member can explain data provenance.
- [ ] One team member can explain route algorithm.
- [ ] Team can state limitations clearly.
- [ ] 3-minute demo rehearsed at least 5 times.

## Final strategic test

Ask:

> If we removed the chatbot UI, would the system still contain useful marine intelligence?

If the answer is **yes**, ORCA has substance.

If the answer is **no**, the team built a wrapper.
