# Design Do Nots

## Never do this

- giant cyan glow around query bar;
- 8 floating data cards visible at once;
- dense dashboard UI in the hero;
- side-view fisherman;
- full-screen sci-fi HUD;
- giant neon PFZ circles;
- heavy blue card backgrounds;
- random glass panels;
- excessive gradients;
- glowing every icon;
- unnecessary minimap;
- unnecessary login/dashboard chrome;
- permanent wind/SST/chlorophyll cards;
- multiple competing accent colors;
- huge headings over the ocean;
- noisy animated particles;
- bouncy spring animations;
- fake sonar every few seconds;
- map labels everywhere;
- giant route arrows;
- over-rounded bubbly components.

## If unsure

Remove the element.

The hero should become better when one unnecessary UI element disappears.
