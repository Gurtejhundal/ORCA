# Design North Star

## Product feeling

ORCA should feel like an intelligence layer that quietly understands the ocean around the fisherman.

The user should feel:

- calm;
- guided;
- informed;
- in control;
- connected to the sea.

The site should never feel:

- noisy;
- over-animated;
- dashboard-heavy;
- over-glowing;
- visually synthetic;
- built from random component libraries.

## Visual formula

```text
85% immersive ocean experience
15% interface
```

The interface must remain subordinate to the ocean.

## Hero benchmark

The reference hero establishes:

- top-down boat;
- large uninterrupted ocean surface;
- restrained PFZ markers;
- one restricted-area boundary;
- minimal left-side tool dock;
- large bottom question bar;
- simple top navigation;
- no unnecessary cards;
- no dashboard chrome;
- no excessive gradients;
- no glowing neon halos.

## Website-wide rule

Every later page should feel like it exists in the **same world**.

That means:
- same glass physics;
- same typography;
- same spacing;
- same dark ocean palette;
- same muted borders;
- same restrained motion;
- same icon treatment;
- same geometric language.
