# Color and Typography

## Base palette

### Ocean
- deep marine blue
- blue-black
- muted teal depth
- desaturated cyan highlights

### Text
- off-white
- soft white
- muted blue-grey metadata

### Status accents
- safe: muted sea-green
- caution: warm amber
- critical: restrained coral/red
- intelligence/active: pale cyan

## Avoid

- electric neon cyan everywhere
- purple gradients
- saturated royal blue cards
- black + bright glowing borders

## Suggested token direction

```text
--bg-deep: #06131b
--bg-ocean: #0b2a3a
--text-primary: rgba(255,255,255,.94)
--text-secondary: rgba(224,237,244,.68)
--border-glass: rgba(255,255,255,.14)
--safe: #77c6a3
--warn: #e2b66a
--danger: #d9796b
--info: #7ebdcf
```

Tune against real background.

## Typography

Primary:
- Geist
- Inter
- SF-like neutral sans
- IBM Plex Sans

Metadata:
- Geist Mono
- IBM Plex Mono
- JetBrains Mono

## Type scale

Desktop:
- hero headline: 48–64px only if used
- section heading: 36–48px
- card/feature heading: 20–26px
- body: 15–18px
- metadata: 11–13px

Hero does not need a giant headline if the visual scene already carries the story.

## Weight

Prefer:
- 400
- 500
- 600

Avoid:
- heavy 800/900 text everywhere.

## Labels

Use compact labels:
- PFZ-01
- WAVE
- SAFE ROUTE
- ALERT
- LIVE
- 12.4 KM

Do not over-explain inside the map.
