# Visual Language

## Spatial character

The UI should float lightly over the ocean.

Use:
- open composition;
- large negative space;
- small anchored controls;
- thin strokes;
- muted shadows;
- contextual overlays.

Avoid:
- stacked dashboard cards;
- boxed sections;
- thick borders;
- over-designed containers;
- card grids everywhere.

## Geometry

Use:
- soft rounded rectangles;
- restrained corner radii;
- thin outlines;
- circular map targets;
- fine route lines.

Avoid:
- bubbly UI;
- extreme pill shapes on every element;
- sharp sci-fi polygons.

## Depth

Use three visual layers:

### Layer 1 — Environment
Ocean, map, route geometry.

### Layer 2 — Intelligence
PFZ, warnings, boundaries, route lines.

### Layer 3 — Interface
Query bar, tool dock, navigation.

Do not mix these layers randomly.

## Shadows

Shadows should be subtle and soft.

Preferred effect:
- slight separation from ocean;
- no floating neon halo.

## Borders

Use low-opacity, cool-neutral borders.

The border should define the glass edge, not call attention to itself.
